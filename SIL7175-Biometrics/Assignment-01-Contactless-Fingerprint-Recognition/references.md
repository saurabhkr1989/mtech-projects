# External datasets used (not hosted in this repo)

Two public fingerprint research databases were used as the raw input for this assignment and are not re-hosted here, for two reasons: their combined size (~25GB) is far beyond what a GitHub repository can practically host, and both are distributed under the originating labs' own access/redistribution terms rather than Saurabh's own data.

- **DS1** (~13.5GB, 19,000+ images, filenames prefixed `SIRE-1_...` / `SI-1_...`) — a public fingerprint image database used for the global-minutia-topology matching pipeline. Request access from the original distributing lab.
- **Cross_Fingerprint_Images_Database** (~11GB, ~6,500 images) — a public cross-sensor fingerprint image database, used for cross-sensor matching evaluation.

The `UNSW 3D Fingerprint Database` ReadMe files in this folder document a third public database referenced during the assignment; see those files for details and the originating source.

What *is* included in this repo: the assignment's own code, report, and the smaller `Fingerprints/` and `processed_contactless_2d_fingerprint_images/` folders, which are small enough to host directly and are the datasets the submitted results were actually generated from.
