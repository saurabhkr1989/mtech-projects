M.Tech coursework, IIT Delhi (Semester II). (Cross-listed as COL7165.)

## Assignments

| # | Topic | Contents |

## Project

- [CUMUL Website Fingerprinting](Project-CUMUL-Website-Fingerprinting) — website fingerprinting over Tor (and variants for YouTube streaming and X/Twitter browsing), implementing the CUMUL feature-based approach from Panchenko et al. (2016).
