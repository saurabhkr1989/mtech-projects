Feature representation

104-dimensional CUMUL vector: 100 interpolation points from cumulative curve C(T) + 4 global statistics (total packets, outgoing count, incoming count, duration)

Dataset scale

500 websites (100 monitored + 400 background) × 50+ instances each = 25,000+ captures. Max 10 concurrent browser instances per run.

Classifiers

SVM with RBF kernel (GridSearchCV over paper ranges) or var-CNN Conv1D deep network (Bhat et al., 2019). Both share the same collection and preprocessing pipeline.

Capture robustness

Tor circuit rotation per retry, bot-detection checks (title/source/body), min 500 packets + bidirectionality validation, auto-blacklist after 5 failures.
