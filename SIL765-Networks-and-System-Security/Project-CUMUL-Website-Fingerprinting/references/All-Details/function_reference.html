cumul.py Phase 3 — CUMUL Core Algorithm Pure-math implementation of the CUMUL feature extraction algorithm
Function Signature What it does Called by / how invoked Returns
parse_pcap
publicI/O		 parse_pcap(pcap_path, layer='cells') Loads PCAP via Scapy rdpcap(). For TCP layer: assigns sign by IP.dst == '127.0.0.1' (loopback = incoming). For cells layer: uses 512-byte Tor cells. Returns signed packet size list T. build_feature_vector() list[int] signed packet sizes T
build_cumulative
publicpure		 build_cumulative(T) Builds the C(T) curve from signed sequence T. Computes aᵢ = aᵢ₋₁ + |pᵢ| (cumulative bytes, x-axis) and cᵢ = cᵢ₋₁ + pᵢ (cumulative signed sum, y-axis). Starting point is (0, 0). build_feature_vector() (a_vals, c_vals) two float lists
sample_features
publicpure		 sample_features(a_vals, c_vals, n_points=100) Creates n_points equidistant x-positions via np.linspace(0, a_max, 100). Uses np.interp() for piecewise linear interpolation of c-values. Normalises variable-length traces to fixed-length vector. build_feature_vector() list[float] length n_points (100)
extract_global_stats
publicpure		 extract_global_stats(T) Computes 4 scalars from signed packet sequence: Nin (count p>0), Nout (count p<0), Sin (sum of incoming bytes), Sout (sum of outgoing bytes). These append to the 100-point vector. build_feature_vector() (Nin, Nout, Sin, Sout)
build_feature_vector
publicentry		 build_feature_vector(pcap_path, layer='cells') Full CUMUL pipeline for one PCAP: parse → build_cumulative → sample_features → extract_global_stats → concatenate. Returns zero vector if trace has <10 packets. Vector layout: [0:100]=CUMUL, [100]=Nin, [101]=Nout, [102]=Sin, [103]=Sout. data._extract_feature_sample()
extract_features.py		 ndarray (104,)
extract_all_features
public		 extract_all_features(pcap_dir, output_path) Batch-extracts features from all PCAPfiles in a directory. Saves feature matrix as .npy and labels as _labels.npy. Prints progress every 10 files. Can be called directly for standalone batch extraction (X, y, labels) or (None, None, None)
