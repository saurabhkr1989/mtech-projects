capture.py Phase 1 — Data Collection
1
Setup environment
Set WIRESHARK_MANUF env var before any Scapy import. Remove SSLKEYLOGFILE to prevent TLS key leakage. Import Scapy, Stem, psutil, undetected-chromedriver (with fallback to Selenium).
driver creation
2
start_tor_instance(worker_id)
  • Launches dedicated tor.exe subprocess for this worker
  • Assigns unique SOCKS port: BASE_SOCKS_PORT + worker_id
  • Assigns unique control port: BASE_CONTROL_PORT + worker_id
  • Waits up to 90 s for 100% bootstrap via Stem control port
  • Returns (proc, socks_port, ctrl_port) or (None, None, None)
browser launch
3
create_driver(socks_port, worker_id)
  • Builds Chrome options: SOCKS5 proxy, random user-agent, random window size
  • Creates isolated profile dir per worker+PID
  • Acquires InterProcessLock (fasteners) before patching chromedriver
  • Injects JS stealth patches (hide webdriver flag, fake plugins/languages)
  • Returns (driver, profile_dir)
start sniffer thread
4
Start Scapy background sniffer
A background threading.Thread calls scapy.sniff() on the capture interface. A threading.Event signals when to stop. All captured packets are collected into a list.
page visit
5
driver.get(url) — navigate to target
  • Wait PAGE_LOAD_WAIT_MIN–MAX (10–15 s) for initial page render
  • Poll document.readyState == complete up to READY_STATE_TIMEOUT (20 s)
  • Wait DYNAMIC_CONTENT_WAIT_MIN–MAX (5–10 s) for React/AJAX loads
  • Simulate human scroll (random 5–15 s)
bot check
_check_bot_block(driver, domain)
4-layer check: (1) page title keywords, (2) page source signatures (Cloudflare, hCaptcha, reCAPTCHA…), (3) URL drift from expected domain, (4) body text < 3000 chars
Bot detected
Stop sniffer. Rotate Tor circuit (NEWNYM). Return (None, reason) for retry.
Page OK
Stop sniffer. Proceed to packet validation.
validate capture
Validate packet trace
Check: packet count ≥ MIN_PACKETS (500) AND trace has both incoming + outgoing packets (bidirectionality)
Invalid trace
Discard. Return (None, "too_few_packets"). Caller retries.
Valid trace
Write PCAP to disk via scapy.wrpcap().
Output label_N.pcap written to data/raw/. Returns (pcap_path, None).
collection_menu.py Phase 1 — Orchestration
1
Load / initialise tracker
Read capture_status.json. If missing, create empty dict. Each site entry tracks: valid, failed_attempts, blacklisted, blacklist_reason, last_updated.
2
Build task queue
For each non-blacklisted site: count valid PCAPfiles on disk. Compute missing = target − valid. Add (site, missing_indices) tasks to queue. Monitored target: 50 instances; background: 1.
3
ThreadPoolExecutor(max_workers=30)
Submit all tasks concurrently. Each worker runs _capture_task(task, status, cap_mod) independently. Results processed in real-time via as_completed().
4
_capture_task: per-instance execution
  • Call capture.capture_site(url, output_path) up to CAPTURE_RETRIES (3) times
  • On each retry: rotate Tor circuit (fresh NEWNYM signal)
  • On success: acquire _tracker_lock, call _mark_success_locked()
  • On all retries exhausted: call _mark_failed_locked()
Failure count ≥ MAX_SITE_FAILURES (7)?
After each failure, check cumulative failed_attempts for this site.
Blacklist site
Set blacklisted=True, record reason. Skip all future tasks for this site.
Continue
Increment failed_attempts. Save tracker. Move to next task.
5
Atomic tracker save
After every capture result (success or fail): acquire _tracker_lock, update in-memory status dict, write capture_status.json atomically. Ensures progress survives crashes.
Output PCAP files in data/raw/. Updated capture_status.json with per-site valid/failed/blacklist counts.
cumul.py Phase 3 — CUMUL Core Algorithm
1
parse_pcap(pcap_path, layer)
Load PCAP via Scapy rdpcap(). For each TCP packet: compute direction from IP.dst == '127.0.0.1' (loopback = incoming). Build signed sequence T = [+size if incoming, −size if outgoing].
T = [+1024, -64, +512, -32, +2048, ...]
2
build_cumulative(T) → C(T)
Iterate over T to compute the cumulative curve. Starting at (0, 0):
aᵢ = aᵢ₋₁ + |pᵢ| (total bytes — x-axis, always grows)
cᵢ = cᵢ₋₁ + pᵢ (signed sum — y-axis, rises on in, falls on out)
a_vals = [0, 1024, 1088, 1600, 1632, 3680, ...] c_vals = [0, 1024, 960, 1472, 1440, 3488, ...]
3
sample_features(a_vals, c_vals, n=100)
Create 100 evenly-spaced x-positions from 0 to a_max using np.linspace(). Use np.interp() to read off the corresponding c-values via piecewise linear interpolation. This normalises variable-length traces to a fixed 100-element vector.
sample_points = np.linspace(0, a_max, 100) v = np.interp(sample_points, a_vals, c_vals) # shape: (100,)
4
extract_global_stats(T)
Compute 4 scalar statistics over the full packet sequence:
Nin = count of incoming packets (p > 0)
Nout = count of outgoing packets (p < 0)
Sin = total bytes incoming
Sout = total bytes outgoing
5
Concatenate → 104-dim vector
Combine interpolated samples with global stats into final numpy array.
vector = np.array(sampled[0:100] + [Nin, Nout, Sin, Sout]) # shape: (104,) # [0:100] = CUMUL interpolation points # [100] = Nin (incoming packet count) # [101] = Nout (outgoing packet count) # [102] = Sin (total incoming bytes) # [103] = Sout (total outgoing bytes)
Output numpy.ndarray of shape (104,) — one feature vector per PCAP file.
extract_features.py & data.py Phase 3 — Feature Pipeline
1
scan_dataset(dataset_root)
Glob all .pcap / .pcapng files. Parse filenames as label_index.pcap. Group into dict keyed by label, sorted by index. Returns a SampleFile dataclass per file.
2
build_split(root, site_count, train_n, test_n)
Select top N sites by sample count. Slice each site's file list: first train_n → train set, next test_n → test set. Validates that all sites have enough captures. Returns (train_files, test_files, labels, error).
3
extract_features(file_paths) — parallel dispatch
  • Workers = FEATURE_EXTRACTION_WORKERS (cpu_count − 1)
  • Uses ProcessPoolExecutor for true parallelism
  • Each worker calls cumul.build_feature_vector(pcap_path)
  • Falls back to sequential if multiprocessing fails
  • Invalid vectors (wrong shape or None) logged as failures
Output X: ndarray (N, 104) feature matrix · y: ndarray (N,) string labels · failures: list of skipped paths
svm_model.py Phase 4 — SVM Training
1
train_from_selection(…)
Entry point. Calls data.build_split() then data.extract_features() for both train and test splits. Raises ValueError if no valid vectors produced.
2
Normalise features
Fit MinMaxScaler(feature_range=(−1, 1)) on X_train. Transform both train and test sets. Encode string labels to integers via LabelEncoder.
grid_search enabled AND min class size ≥ 2?
Checks min(class_counts.values()) to determine viable CV folds.
GridSearchCV
Search C=[2¹¹…2¹⁷], γ=[2⁻³…2³] with StratifiedKFold (up to 10 folds). Select best estimator.
Direct fit
Use config defaults C=1.0, γ='scale'. Fit single SVC directly.
3
Evaluate & cross-validate
Compute train accuracy, test accuracy, confusion matrix. Run cross_val_score on the fitted model for mean ± std CV accuracy. Generate classification report.
4
save_artifacts(model, scaler, label_encoder, metadata)
Persist all artefacts to data/models/svm/ via joblib.dump(). Write experiment metadata (timestamp, best params, accuracy) to metadata.json.
Output files in data/models/svm/ svm_model.pkl · scaler.pkl · label_encoder.pkl · metadata.json

var-CNN path

test.py Phase 5 — Model Testing CLI
1
Load trained artefacts
Call svm_model.load_artifacts(). Load svm_model.pkl, scaler.pkl, label_encoder.pkl, metadata.json. Abort with clear error if any file missing.
2
Load & extract test features
Re-run data.build_split() for test portion. Call data.extract_features(test_files) to get X_test. Apply saved scaler: scaler.transform(X_test). Encode labels.
3
Predict & score
Run model.predict(X_test_scaled). Compute accuracy, confusion matrix, per-class precision/recall/F1. Also runs evaluate.py for full report generation.
OutputConsole metrics report. JSON result saved to results/. Graphs generated via graphs.py.
evaluate.py Phase 5 — Evaluation Engine
1
Check dependencies & load artefacts
Verify model, scaler, label encoder files exist. Load features.npy if present. Otherwise re-extract from PCAPfiles.
2
Compute metrics
  • Overall accuracy: accuracy_score(y_true, y_pred)
  • Per-class: precision, recall, F1 via classification_report()
  • Confusion matrix: confusion_matrix()
  • Top-k accuracy (k=1, k=5)
3
Save JSON report
Write full results dict (accuracy, params, labels, confusion matrix, timestamp) to results/eval_TIMESTAMP.json.
Outputresults/eval_TIMESTAMP.json — full evaluation report with all metrics.

scaler.py Utility — Feature Normalisation
1
fit_scaler(X_train)
Instantiate MinMaxScaler(feature_range=(−1, 1)). Call .fit(X_train) to learn per-feature min/max from training data only. Prevents data leakage from test set.
2
transform(X)
Apply learned min/max scaling. Each feature i: x' = 2*(x − min_i)/(max_i − min_i) − 1. Applied to both train and test (using train-fitted params).
3
save / load scaler
Persist via joblib.dump(scaler, 'scaler.pkl'). Reload at test time with joblib.load() to ensure identical transformation.
Outputscaler.pkl saved to data/models/svm/. Returns X_scaled in range [−1, 1].
site_registry.py Utility — Site List Management
1
Load master_sites.json
Reads the master site registry. Contains 500 entries: 100 monitored (high-value, 50 captures each) and 400 background (1 capture each). Zero URL overlaps verified at config load time.
2
labels_for_scope(scope)
Returns ordered list of site labels filtered by scope: "monitored" = 100 sites, "background" = 400 sites, "all" = 500 sites. Used by data.py to restrict dataset scanning.
OutputOrdered list of site label strings used for PCAP filename matching and training scope.

merge_data.py Utility — Dataset Merging
1
Prompt for two source directories
User provides path to folder A and folder B. Both must be valid PCAP directories with label_index.pcap naming convention.
2
Scan & de-duplicate
Scan both directories. For each label, merge file lists. Re-index files sequentially (avoid duplicate index collisions). Skip files that already exist in destination.
3
Copy to output directory
Copy all files to merged destination with corrected sequential naming. Print per-label counts before and after merge.
OutputMerged PCAP directory with re-indexed filenames. Console report of file counts per label.
