## Project

Course project: comparison of three face-recognition algorithms — Fisherfaces (TPAMI 1997), PETALface (WACV 2025), and FaceMoE (recent improvement).

- [Project/Course-Material](Project/Course-Material) — reference lecture material on face recognition used for the project.
- [Project/Final-Report](Project/Final-Report) — final project report (PDF).
- **Project code, datasets, and full results live in a separate private GitHub repository**: [saurabhkr1989/Face-Recognition](https://github.com/saurabhkr1989/Face-Recognition) — kept separate per Saurabh's request, since it bundles ~500MB of face-recognition datasets (ORL, Georgia Tech, TinyFace) alongside the Fisherfaces/PETALface/FaceMoE implementations, GUI, and reports. Not duplicated into this public monorepo.
