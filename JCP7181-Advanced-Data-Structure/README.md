# Advanced Data Structure and Algorithms Lab (JCP7181)

M.Tech (Cyber Security), Semester I, IIT Delhi.

Each assignment folder contains the problem statement (`Problem-Statement.pdf`), the report
(`Report.pdf`/`Report.docx`), source code, and test cases used.

| # | Topic |
|---|-------|
| [01](./Assignment-01-Student-Directory-Hashing) | Student directory lookup via hashing (chaining, linear probing, quadratic probing) |
| [02](./Assignment-02-Payment-Network-Batch-Routing) | Shortest path with ordered waypoints (payment batch routing through audit gateways) |
| [03](./Assignment-03-Social-Media-System-and-Huffman-Coding) | Part 1: social connections backend; Part 2: Huffman coding compression/decompression |
| [04](./Assignment-04-Fractional-and-01-Knapsack) | Part 1: fractional knapsack; Part 2: 0/1 knapsack |
| [05](./Assignment-05-IP-Address-Analysis) | Reconstructing and clustering corrupted IPv4 addresses from log data |

Compiled binaries, build artifacts, and virtual environments are intentionally excluded (see repo root `.gitignore`).
